# T10-1 · CORE-7000 — BEST VALUE ribbon drop-shadow

**What was wrong:** The homepage "Formation Packages" section renders the All Inclusive
card via `PackageGrid` block → shared `PackageGridCard` component
(`src/components/shared/PackageGridCard/index.tsx`). Its `badge` style
(`PackageGridCard.styles.ts`) — the diagonal "BEST VALUE" ribbon — had no `box-shadow` at
all, so the ribbon rendered flat instead of casting the soft drop-shadow live has. A
sibling component in this repo, `RecommendedPackages` (`RecommendedPackages.styles.ts`
`ribbonLabel`), already implements the identical ribbon pattern correctly, including the
shadow — that was the reference for the fix.

**What I changed:** One line in
`src/components/shared/PackageGridCard/PackageGridCard.styles.ts`, the `badge` key —
appended `shadow-[0_5px_10px_rgb(0_0_0/0.1)]` (byte-for-byte the same arbitrary-value
class already used and proven-compiling in `RecommendedPackages.styles.ts`'s
`ribbonLabel`). This compiles to `box-shadow: 0 5px 10px 0 rgb(0 0 0 / 0.1)`, matching the
ticket's expected `rgba(0,0,0,0.1) 0px 5px 10px 0px` exactly. No other properties on
`badge` touched — colour/size/angle/text classes are untouched. `badgeClip` (the
`overflow-hidden` corner container, `hidden` below `min-[1023px]`) was not touched either,
so the no-ribbon-at-360/768 behaviour is unchanged.

**How I verified it:**
- `bun run ts` — clean, no type errors.
- Confirmed via `git diff` that only the one Tailwind class was added, nothing else in
  `badge` changed.

  is invalid, it points out of the filesystem root` on `bun run dev` for every lane today
  (T1/T8 hit the same thing per HEARTBEAT — T7 flagged this exact class of issue in the
  prior round too). I could not get a live HTTPS Playwright screenshot at 1024/1800
  through the normal path. As a one-off local-only workaround (never committed) I ran
  `next dev --webpack` on plain HTTP to get *a* running server and confirmed the page

  manage to get a clean computed-`box-shadow` read before cleaning the workaround up (the
