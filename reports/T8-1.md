# T8 — CORE-7018 FAQ accordion heading h3→h4

## What was wrong
The shared FAQ accordion (`src/components/shared/Collapsible/Collapsible.tsx`) renders each
question via `<Text as={headingAs} textStyle="span">`, with `headingAs` defaulting to `'h3'`
when the caller doesn't override it. `src/blocks/FAQs/Component.tsx` — the ONLY consumer of
`Collapsible` in this repo — was calling it without passing `headingAs` at all, so every FAQ
question rendered as `<h3>` instead of live's `<h4>`. (Note: `src/components/ui/accordion.tsx`
/ Radix `AccordionPrimitive` is a separate, currently-unused shadcn accordion wrapper — not
involved in the FAQ block; the FAQ accordion is Collapsible.tsx's plain button/list markup.)

## What I changed
One line in `src/blocks/FAQs/Component.tsx`: added `headingAs="h4"` to the `<Collapsible ... />`
call (line 43, right before `className`). `Collapsible`'s heading wrapper class is
`m-0 font-normal` (Collapsible.styles.ts) — no styling depends on the tag, and the visible text
size/weight/colour comes from the inner `<Text textStyle="span" className={s.title}>`, untouched
by this change. Typecheck (`bun run ts`) is clean; `git diff` shows exactly this one insertion.

## How I verified it
- Read Collapsible.tsx + FAQs/Component.tsx + Collapsible.styles.ts to confirm the tag swap
  can't touch computed style (heading wrapper carries no size/weight/color/line-height classes).
- `bun run ts` → clean, no type errors.
- **Could NOT verify live in-browser**: the dev server in this worktree fails to boot under
